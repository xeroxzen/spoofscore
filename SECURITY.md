# Security policy

## Reporting a vulnerability in spoofscore

Examples: a record that makes spoofscore report `protected` for a domain that can be spoofed, or input that injects markup into the web page. Report it privately:

- Use [GitHub private vulnerability reporting](https://github.com/xeroxzen/spoofscore/security/advisories/new), or
- Email andilembele020@gmail.com with the subject `spoofscore security`.

Include the version, the records or input, and what you expected. You'll get an acknowledgement within 3 working days.

## Found a spoofable domain?

That's a configuration issue for the domain's owner, not a vulnerability in spoofscore. Tell the owner privately, through their published security contact if they have one. Don't publish a named organisation's results before they've had a chance to fix them.

## Supported versions

Only the latest release receives fixes.
